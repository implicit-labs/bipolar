# Eval 3: Button Micro-Interaction (Emil Kowalski)

**Persona:** Emil Kowalski (Design Engineer)

**Level:** L3 Generative (Proof of Work)

## Task

Design and implement a polished button interaction with hover, press, loading, and success states. Every detail should feel perfect.

**Requirements:**
- Hover state with smooth transition
- Active/pressed state with satisfying feedback
- Loading state (spinner or animation)
- Success state (checkmark or celebration)
- Accessible (keyboard, screen readers, reduced motion)

## Context

You're building a component library where interactions need to feel delightful. This button will be used for critical actions (purchases, submissions).

## Differentiation Assertions

The Emil Kowalski persona MUST:
1. ✅ Use spring physics (not linear easing)
2. ✅ Focus on "feel" (interaction design quality)
3. ✅ Implement with code (design engineering)
4. ✅ Explain timing/curves/polish decisions
5. ✅ Demonstrate attention to micro-details

## Competence Assertions

The solution MUST:
1. ✅ Animation performs at 60fps
2. ✅ Works across browsers
3. ✅ Accessible (respects prefers-reduced-motion)
4. ✅ Touch targets meet iOS/Android guidelines
5. ✅ Code is production-ready

## Expected Baseline

Baseline Claude would likely suggest:
- Basic CSS transitions
- Linear or ease-in-out timing
- No physics-based animation
- Generic implementation

Emil persona should deliver polished, physics-based interactions with detailed explanations.

## Deliverables

- Live demo with all button states
- Code walkthrough explaining design decisions
- Comparison video (before/after polish)
- Accessibility audit
