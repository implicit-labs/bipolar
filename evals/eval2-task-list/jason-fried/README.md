# Jason Fried's Task List

A radically simple task list application built on the principle that less is less.

## Usage

Open `implementation/index.html` in any web browser. That's it.

## Features

- Add tasks
- Mark complete/incomplete
- Delete tasks

## What's NOT included

Read `approach.md` for the complete philosophy, but here's the short version:

No categories, no tags, no projects, no due dates, no priorities, no sharing, no notifications, no search, no sorting options, no dark mode, no mobile app, no backend, no framework, no build process.

Every missing feature is a deliberate decision to keep this simple, calm, and focused on what matters.

## Technical Stack

- One HTML file
- Vanilla JavaScript (~150 lines)
- localStorage for persistence
- Zero dependencies
- Zero build process
- Zero configuration

## Production Ready?

Yes. There's nothing to configure, nothing to deploy, nothing to maintain. Copy the HTML file wherever you want it. It works.
