# Eval 3: Product Strategy - Unbundling Opportunity (Julian Lehr)

**Persona:** Julian Lehr (Product strategist, "Unbundling" essays)

**Level:** L2 Applied Judgment (Thinking)

## Task

Analyze a monolithic product (like Craigslist or Dropbox) and identify unbundling opportunities. Which single-purpose products could be extracted?

**Product to Analyze: Project Management Suite**

Current features (all in one tool):
- Task management
- Time tracking
- File storage
- Team chat
- Client invoicing
- Gantt charts
- Resource planning
- Bug tracking
- Wiki/documentation

## Context

A startup wants to compete with established project management tools but can't beat them head-on. Where's the unbundling opportunity?

The Julian Lehr persona MUST:
1. ✅ Use "unbundling" strategic framework
2. ✅ Identify specific feature→product opportunities
3. ✅ Analyze why unbundling creates value
4. ✅ Reference historical unbundling examples
5. ✅ Focus on strategic insights, not just features

## Competence Assertions

The analysis MUST:
1. ✅ Identify real market opportunities
2. ✅ Explain value creation mechanism
3. ✅ Consider competitive dynamics
4. ✅ Assess market size and viability
5. ✅ Provide actionable startup ideas

Julian persona should deliver strategic product insights.
