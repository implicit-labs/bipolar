# v0 Production Shipping

Based on Guillermo Rauch's v0 workflows and AI-assisted development philosophy.

---

## Steps

### 1. Start with the Interface
Describe what you want in natural language. Provide references and inspirations, not overly prescriptive directions. Let AI generate the initial UI.

### 2. Delete Everything Unnecessary
Simplicity through reduction. "Minimize the number of concepts & modes." Strip to the essential experience.

### 3. Iterate with Natural Language
Use direct, casual language with AI. "Make it more jazzy." "Fix layout shift." Break large projects into smaller components to manage context windows effectively.

### 4. Create Feature Branches
Work in branches. Include production considerations from the start — rate limiting, abuse prevention, error handling.

### 5. Generate PR with Preview
Single-click PR generation with auto-descriptions. Automatic Vercel preview deployment for team review.

### 6. Team Review Before Merge
Share the preview URL. Review real working software, not code diffs alone. Merge when the demo convinces.

---

## Philosophy

> "Code is cheap. Taste is rare. Muscle isn't memorization; it's taste."

AI handles implementation. Humans provide taste — turning user needs and product visions into live pixels. The workflow is about coaching AI through feedback loops, not writing code character by character.
