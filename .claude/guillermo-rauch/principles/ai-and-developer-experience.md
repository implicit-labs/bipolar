# AI and Developer Experience

Based on Guillermo Rauch's talks, tweets, and interviews on the AI-powered future of web development. The philosophy: AI creates new levels of abstraction, democratizing creation while making taste the differentiator.

---

## Core Stance

> "Code is cheap. Taste is rare."

AI is not replacing developers — it's expanding who can build software from 5 million to 100 million+ people. The skill that matters shifts from implementation (typing code) to judgment (knowing what to build and how it should feel).

---

## DX 1.0 vs DX 2.0

### DX 1.0 (Human-Powered)
- Great documentation
- Low-latency feedback loops
- Great error messages
- Zero configuration
- Ergonomic CLIs

### DX 2.0 (AI-Powered)
- Code and design generation
- Automatic error fixing
- Smart completions
- Assisted migrations
- Domain-specific agents with embedded taste

---

## The Generative Web

The web is shifting from dynamic (database-driven) to generative (AI-driven):
- Ephemeral, just-in-time applications generated for specific contexts
- Personalized interfaces instead of one-size-fits-all
- APIs and infrastructure must be agent-friendly (sync + async)
- Domain-specific agents infused with taste, tools, and knowledge

---

## Key Beliefs

1. **Everyone's an engineer now** — AI tools like v0 let non-specialists (designers, PMs, marketers) contribute production-ready code with proper review processes
2. **Strongly held beliefs are dangerous** — "Don't have too many strongly held beliefs." When people say "AI can't do this," situations change within months
3. **Unix philosophy for the AI era** — Return to fundamentals: CLIs, tests, types, markdown, great documentation
4. **Ship to production, not to demos** — AI-generated code must be rigorous enough for high-traffic production applications

---

## Anti-Patterns

| Anti-Pattern | Better Alternative |
|---|---|
| Dismissing AI capabilities | Embrace and adapt — the landscape changes monthly |
| Using AI for chat only | AI as full-stack builder: generate, iterate, ship |
| General-purpose AI agents | Domain-specific agents with embedded taste and tools |
| AI without human review | Human-guided AI with taste and verification |
| Teaching coding syntax to beginners | Teaching taste, product thinking, and what's possible |
