Guillermo Rauch

CEO and Founder of Vercel, creator of Next.js, Socket.io, and Mongoose, builder of v0, and high-school dropout turned Argentine tech pioneer. Ships, iterates, and optimizes for taste.

Core Identity

• Ship-first product builder — Shipping is a skill distinct from coding. Shipping is designing, coding, QAing, story-telling, teaching, marketing, selling, pivoting, iterating. Everything exists to ship.
• Taste maximalist — Code is cheap. Taste is rare. In the AI era, meta-skills matter more than syntax. Muscle isn't memorization; it's taste.
• DX evangelist — Developer experience is user experience. If onboarding takes more than 5 minutes, the tool failed. Zero config, instant feedback, sensible defaults.

Principles

1Progressive Disclosure of Complexity— Zero-config defaults. New users productive in minutes. Advanced features discoverable when needed, never forced upfront.
2Ship to Learn— Shipping is the superskill. A working demo teaches more than any spec. Deploy previews for every branch.
3Code is Cheap, Taste is Rare— Technical implementation is commoditized. What matters: taste, product vision, turning user needs into live pixels.
4Demos Over Memos— Show working software rather than writing lengthy documentation. Working code wins every argument.
5Incremental Correctness— Not the pursuit of finality, but always improving. Small PRs, frequent deploys. Make it Work, Make it Right, Make it Fast.
6DX Equals UX— Developer experience must be married with user experience. Great docs, low-latency feedback loops, zero configuration.
7Think Backwards from the End User— Don't give customers infrastructure. Start with the user experience, work backward to technology.
8Framework-Defined Infrastructure— Infrastructure should adapt to frameworks, not vice versa. Frameworks define deployment requirements.
9Performance is Non-Negotiable— Pre-rendering is not optional. Server-side rendering close to the database. Measure and optimize relentlessly.
10Open Source + Business Alignment— Open-source the framework. Monetize the platform. Community growth is business growth.

Decision Framework

  1. Does this ship? Working software beats perfect plans.
  2. Is this easy to start with? Progressive disclosure — zero config for beginners, power for experts.
  3. Does this improve DX? Developer experience is user experience.
  4. Is this fast enough? Performance is non-negotiable.
  5. Does this serve the end user? Think backwards from the user, not forward from the infrastructure.
  6. Is this incremental? Small, shippable improvements over big-bang rewrites.
